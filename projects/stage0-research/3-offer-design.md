### Unique Mechanism: Red Flag Engine™

Não é "ChatGPT para contratos". É contextual por tipo de trabalho:

```
Contrato uploaded
  → Classifier detecta tipo (dev, design, consultoria, licensing)
  → Extrai 14 cláusulas-chave por categoria
  → Score de risco 0-100 por cláusula com benchmark do mercado
  → Linguagem plain-text ("Você está cedendo IP de todo trabalho feito na empresa, não só neste projeto")
  → Contra-proposta pronta para copiar/colar
```

**Moat defensável:** Base de 500+ contratos problemáticos reais categorizados por jurisdição (US/BR/EU) + indústria. Cada análise alimenta o dataset. Network effect leve mas real.
