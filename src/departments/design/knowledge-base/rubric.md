# Design Department — Evaluation Rubric

Score outputs 1-10.

## Scoring Dimensions

### Brand Coherence (0-2)
- 2: Colors, typography, and personality form a unified, distinctive brand
- 1: Elements exist but lack cohesion
- 0: No brand identity

### CSS Token Quality (0-3)
- 3: Complete token system covering colors, typography, spacing, radii, shadows
- 2: Most tokens present but incomplete
- 1: Partial tokens
- 0: No tokens

### HTML/CSS Quality (0-3)
- 3: Complete landing page, semantic HTML, responsive, uses tokens consistently
- 2: Landing page exists but missing sections or not responsive
- 1: Incomplete page
- 0: No HTML output

### Conversion Effectiveness (0-2)
- 2: Clear CTA hierarchy, social proof, benefit-focused copy, urgency elements
- 1: Basic CTA but missing conversion elements
- 0: No conversion thinking

**Pass threshold: 7/10**
