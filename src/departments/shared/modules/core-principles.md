# Core Principles (Shared)

- **Revenue First:** Every deliverable must move MRR or Leads. If it doesn't, question why it's being built.
- **Simplicity over Complexity:** Avoid over-engineering. Deliver only what is requested.
- **Production-Ready:** All code must be runnable, documented, and following best practices.
- **Atomic Tasks:** No task should exceed 2 atomic leaves of work.
- **Strict Formatting:** Follow project-specific naming conventions and folder structures.
- **Security First:** Never expose secrets, always validate inputs.
