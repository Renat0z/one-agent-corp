# Engineering Department — Evaluation Rubric

Score outputs 1-10.

## Scoring Dimensions

### Code Completeness (0-3)
- 3: All files complete, no TODOs in logic, runnable code
- 2: Most files complete, minor gaps
- 1: Significant placeholders or missing implementations
- 0: Pseudocode or skeleton only

### TypeScript Quality (0-2)
- 2: Strict types, no `any`, explicit return types, proper interfaces
- 1: Types present but inconsistent
- 0: Untyped or heavy use of `any`

### Security Practices (0-3)
- 3: Input validation, auth checks, rate limiting, no exposed internals
- 2: Input validation and auth, minor gaps
- 1: Some validation but missing security layers
- 0: No security considerations

### Architecture Quality (0-2)
- 2: Clean separation of concerns, follows Next.js conventions, reusable patterns
- 1: Works but monolithic or inconsistent patterns
- 0: No clear architecture

**Pass threshold: 7/10**
