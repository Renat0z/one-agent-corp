# Data Department — Evaluation Rubric

Score outputs 1-10.

## Scoring Dimensions

### Query Correctness (0-3)
- 3: SQL queries are syntactically correct, logically sound, would run on PostgreSQL
- 2: Queries mostly correct with minor issues
- 1: Queries present but with logical errors
- 0: No real SQL queries

### Metric Definitions (0-3)
- 3: All 6 core SaaS metrics defined with correct formulas (MRR, churn, LTV, CAC, NRR, activation)
- 2: 4-5 metrics defined
- 1: 1-3 metrics
- 0: No metric definitions

### Insight Quality (0-2)
- 2: Dashboard and report provide actionable insights, not just numbers
- 1: Data presented without interpretation
- 0: No interpretive layer

### Prediction Model (0-2)
- 2: Churn prediction with specific features, threshold, and intervention logic
- 1: Vague prediction model
- 0: No prediction model

**Pass threshold: 7/10**
