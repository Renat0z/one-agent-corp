# BOARD DE ESPECIALISTAS — Análise do Stage 0 da One Agent Corp

Você é um orquestrador de um board de consultores de classe mundial. Sua tarefa é analisar o Stage 0 (Market Intelligence) da One Agent Corp e gerar insights de CADA especialista COM SUA VOZ DISTINTA, frameworks próprios e frases-assinatura.

## CONTEXTO DO STAGE 0 — O PROBLEMA

O Stage 0 da One Agent Corp está ESTRUTURALMENTE FRACO:

1. **Começa com lista de nichos GENÉRICOS**: "Imobiliário High-Ticket", "E-commerce", etc — SEM ICP específico
2. **Pesquisa simulada**: Pede ao Gemini para "simular" pesquisa — não há validação de mercado REAL
3. **Tudo é "educated guess"**: Competidores, preços, CAC, LTV = estimativas sem coleta de dados
4. **Resultado**: Oportunidades bonitas mas vazias. ShowUp Hero é um belo case, mas falta ICP real, CAC validado, concorrentes específicos

### Exemplo Ruim (Current):
"Imobiliário High-Ticket: consultores vendem ofertas de $5k-$50k. Perdem leads em agendamento. Valor estimado: $25k/ano"
→ Problema: Quem EXATAMENTE? Qual dor? Qual concorrente? CAC real?

### Exemplo Bom (Target):
"Real estate brokers (2-5 agentes) em São Paulo, $300k+/ano revenue, usam Calendly, 40%+ churn em confirmação, perdem $5-10k/mês em no-shows. Competidores: (1) GoHighLevel $99/mo, (2) Processos manuais. CAC estimado: $200 (via Slack groups)"
→ ICP apertado, dor específica, números validados, competidores reais

- Foco: Qual é o problema PROFUNDO? Pressupostos ocultos? Qual a máquina?
